# README

## Công nghệ sử dụng

- Python
- Jupyter Notebook
- Các thư viện phân tích dữ liệu và học sâu (ví dụ: NumPy, Pandas, Matplotlib, v.v.)

## Cách hoạt động

1. Mở file `Week4.ipynb` bằng Jupyter Notebook hoặc VS Code.
2. Thực hiện từng cell để chạy các đoạn mã phân tích dữ liệu và học sâu.
3. Quan sát kết quả trực tiếp trên notebook.

## Kết quả

- Hiển thị các bảng dữ liệu, biểu đồ trực quan hóa và kết quả huấn luyện mô hình (nếu có).
- Phân tích, nhận xét và đánh giá kết quả được trình bày trong các cell markdown của notebook.
